## 1. Epistemic Hygiene: Fit Rubric & Source Grading

The main failure mode of universal philosophical schemas (often raised against Priest's Inclosure Schema) is **shoehorning** — stretching an argument until it vaguely resembles a box. Every Pass 2 entry will carry two explicit tags:

- **Structural fit grade:**
  - `CLEAN_FIT` — maps onto an explicit regime + shape + declared rules without distorting the argument.
  - `STRETCH` — requires an extra operator beyond $\{Y, N\}^2$ (ordering, modality, multi-valued options, or domain-of-things instead of statements).
  - `HONEST_NON_FIT` — looks OP-adjacent on the surface, fails the coupling criterion or does not live in the 2-question self-application space.
- **Source grade:**
  - `VERIFIED_PRIMARY` — checked against the primary text directly.
  - `VERIFIED_SECONDARY` — checked against a cited scholarly reference (e.g., SEP, Mackie 1964, Priest 1995, Burnyeat 1976, Castagnoli 2010).
  - `LEAD` — recalled or noted as a candidate, not yet checked against a source.

## 2. Candidate Rows for the Atlas

### Group A — Classic Truth-Adjacent Rows (consolidating & extending the original 5 rows)
1. `Is it known? / Is it true?` (`NESTED`, plus `reflection` / `conjunctionDist`) — Sextus, Fitch, Kaplan–Montague Knower, plus newly surfaced `BR_REV` (*"every truth is known"* cannot be `NY`) and `EN`.
2. `Is it believed? / Is it true?` (`FREE`, plus `dissenter` / `performative` / `conjunctionDist`) — Protagoras (2-item vs. 3-item catch), Prior (1961), Buridan/Burge, Smullyan, Moore.
3. `Is it indubitable? / Is it true?` (`NESTED` via polarity flip of `can it be doubted?`) — Can's statement $A$ $\cong$ Sextus, Descartes's cogito, Augustine's *si fallor, sum*.
4. `Can it be conceived? / Does it exist?` (`STRETCH`: domain of things + Characterisation Principle) — Parmenides, Gorgias, Berkeley, Anselm, Gaunilo, **plus** [`origins/alpha_and_the_one_draft_d1.md`](../origins/alpha_and_the_one_draft_d1.md) §3 (uniqueness of the residual `*` as a Berkeley-shaped move).
5. `Is it provable? / Is it true?` (`NESTED`, plus `lob`) — Gödel I & II, Henkin/Löb, Tarski (`MIRROR`), Turing (`MIRROR`), Cantor & Russell (`OPPOSITE` + diagonal equality).

### Group B — Non-Truth Rows (the largely unmapped territory)
6. **Erotetic / VD Foundation:**
   - `Is it a question? / Does it have an answer?` (already worked in `origins/what_is_a_question_op_run_2026-11-12.md`; formalize via the explicit erotetic T-schema + multi-valued Millionaire board).
   - `Is it a question? / Does it have a truth value?` (unrun VD pair #2).
   - `Is it a question? / Does asking it require already knowing the answer?` (unrun VD pair #3 — **Meno's paradox**).
   - `Is it defined? / Is it meaningful?` (VD's Punnett square, plus how *The Chain*'s disciplined-interpreter model answers Priest's revenge via Turing non-convergence rather than dialetheism).
7. **Philosophy of Science / Demarcation:**
   - `Is it verifiable? / Is it meaningful?` (Logical positivism's verification principle turned on itself — A. J. Ayer / Carnap).
   - `Is it falsifiable? / Is it scientific?` (Popper's demarcation criterion applied to itself).
8. **Deontic, Legal & Political:**
   - `Is it obligatory? / Is it permissible?` (`NESTED`: ought implies may; self-referential obligation puzzles).
   - `Is it amendable? / Is it a valid constitutional rule?` (Peter Suber's *Paradox of Self-Amendment*).
   - `Is it commanded (or willed)? / Is it good?` (Euthyphro dilemma as a bridge-rule fork).
9. **Decision, Agency & Prediction:**
   - `Is it predictable? / Is it freely chosen?` (fatalism, Newcomb/predictor loops, Scriven's prediction paradox).

## 3. Two Analytical Deliverables for Pass 2

1. **The Rule-Exit Matrix:** For every `COLLAPSE` ($\emptyset$) row in the Atlas, list the exact set of jointly inconsistent rules and tabulate which rule each historical school chose to sacrifice (e.g., Priest drops consistency; Tarski/Russell stratify the domain; VD replaces syntactic totality + `"gibberish"` with normalisation + non-convergence on concrete interpreters; Mackie restricts operational vs. absolute force).
2. **The Honest Non-Fit Shelf:** Deliberately test 3–5 famous philosophical moves that *look* tempting but should be refused (e.g., Hume's is–ought gap, Quine's indeterminacy of translation, Kant's synthetic *a priori*, trivial syntactic self-reference, and quantitative symmetry arguments like the mass-estimator reciprocal swap) to keep the Atlas's borders sharp.
